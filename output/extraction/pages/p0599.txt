The output voltage holds the voltage obtained during the previous clock phase.
In clock phase W2, the charge of the capacitors which belong to the switches connected to
ground, is transferred to the output capacitor 8C.
The output voltage then changes depending on the charge transferred from these capacitors.
Note that this circuit suffers from the same problems as switched capacitors filters. They can
easily achieve a 70 dB dynamic range corresponding to about 12 bit, but not much more.

The binary code deter-

Now, of course, the mis-

Moreover glitches can

Glitches can be avoided however, by using a thermometer code rather than a binary code.
