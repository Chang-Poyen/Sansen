For a differential output,
two transistors to ground
provide only a first-order
characteristic – there is only
one single pole.
This is obvious for the cir-
cuit on the left. Since there
is only one capacitance, only
one pole can emerge.
However, this circuit can
easily be converted to the
circuit on the right. We take
two capacitances in series
with double the value and
then ground the node
between both capacitances.
This is how the circuit on the right is derived from the first one. For AC they are exactly the
same. They have the same pole!
To make it slightly more intriguing, we could wonder what happens if there is some asymmetry.
For example, if one capacitance is slightly larger than the other one, how can it create a pole
with the same value?
In this case, we find two poles, but we also find a zero inbetween, to ensure a first-order roll-off.
